# HKHS 屋邨行動內容工作台

1. 雙擊 `HKHS-Content-Studio.html`。
2. 選擇 `site/content/estate-actions.json` 或 `site/content/videos.json`。
3. 選擇繁體中文、簡體中文或 English，直接修改文字。
4. 按「匯出更新內容」，把下載的同名 JSON 覆蓋原檔。
5. 如要替換圖片，在相應 EA 卡片選擇照片，下載自動轉換的 `EA-XX.webp`，然後覆蓋 `site/public/media/estate-actions/` 內同名檔案。
6. 完成後交給網站維護人員或 Codex 檢查及發佈。

工作台只在本機運作，不會成為公開網站的管理入口。瀏覽器草稿只儲存在目前電腦和瀏覽器；正式內容仍以 `estate-actions.json` 為準。
